## IP纯净度到底指什么，平台为什么在意它

IP纯净度主要由三件事决定：IP的注册类型（数据中心IP、ISP住宅IP还是家庭宽带IP）、归属地和业务地区是否一致（原生IP）、以及这个IP段之前被什么人用过（新上线的IP段通常更干净）。

平台风控对这三点都敏感。TikTok是典型例子——机房IP容易被判定为批量操作环境，常见后果是限流、0播放甚至封号；住宅属性的IP在风控眼里接近“正常网民”。电商账号和银行风控的逻辑类似，第一步都是看你的IP像不像真实用户。

第三方测评也印证过这一点：有长期使用丽萨主机的站长提到，拿到的住宅IP没有被平台标记为数据中心IP，运营的TikTok账号数据正常、没触发过风控；测评文章还普遍提到一个规律——新IP段上线初期最干净，这个阶段做TikTok更容易拿到自然流量。当然，IP纯净度会随使用人数变化，这点没法承诺，买之前想清楚即可。
